# BunnyACE - Техническая документация

## Обзор системы

**BunnyACE** - это модуль для 3D-принтеров на базе Klipper, предназначенный для управления многоматериальной системой подачи филамента ACE Pro. Система обеспечивает автоматическую смену инструментов, сушку филамента, контроль подачи материала и поддержку технологии "бесконечной катушки".

## Архитектура системы

### Основные компоненты

1. **MmuRunoutHelper** - Помощник для обработки событий закончившегося филамента
2. **BunnyAce** - Основной класс управления системой ACE Pro

### Связь и протокол передачи данных

- **Последовательный интерфейс**: Связь через UART/USB
- **Протокол**: JSON через последовательный порт с контролем целостности CRC
- **Скорость передачи**: По умолчанию 115200 бод

## Параметры конфигурации

### Обязательные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `serial` | строка | Путь к последовательному порту | `/dev/ttyACM0` |
| `extruder_sensor_pin` | строка | Пин датчика филамента экструдера | `^gpio21` |

### Дополнительные параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `baud` | целое число | 115200 | Скорость последовательного порта |
| `toolhead_sensor_pin` | строка | None | Пин датчика филамента головки инструмента |
| `feed_speed` | целое число | 50 | Скорость подачи филамента (мм/с) |
| `retract_speed` | целое число | 50 | Скорость втягивания филамента (мм/с) |
| `toolchange_retract_length` | целое число | 100 | Длина втягивания при смене инструмента (мм) |
| `toolhead_sensor_to_nozzle` | целое число | 0 | Расстояние от датчика головки до сопла (мм) |
| `max_dryer_temperature` | целое число | 55 | Максимальная температура сушилки (°C) |
| `poop_macros` | строка | - | G-code макрос для очистки сопла |
| `cut_macros` | строка | - | G-code макрос для обрезки филамента |

## G-code команды

### ACE_START_DRYING
**Назначение**: Запускает процесс сушки филамента в ACE Pro

**Синтаксис**: `ACE_START_DRYING TEMP=<температура> [DURATION=<время>]`

**Параметры**:
- `TEMP` (обязательный) - температура сушки (1-55°C)
- `DURATION` (опциональный) - время сушки в минутах (по умолчанию: 240)

**Пример**: `ACE_START_DRYING TEMP=45 DURATION=180`

### ACE_STOP_DRYING
**Назначение**: Останавливает процесс сушки филамента

**Синтаксис**: `ACE_STOP_DRYING`

**Параметры**: Нет

### ACE_ENABLE_FEED_ASSIST
**Назначение**: Включает помощь при подаче филамента для указанного слота

**Синтаксис**: `ACE_ENABLE_FEED_ASSIST INDEX=<номер_слота>`

**Параметры**:
- `INDEX` (обязательный) - номер слота (0-3)

**Пример**: `ACE_ENABLE_FEED_ASSIST INDEX=0`

### ACE_DISABLE_FEED_ASSIST
**Назначение**: Отключает помощь при подаче филамента

**Синтаксис**: `ACE_DISABLE_FEED_ASSIST [INDEX=<номер_слота>]`

**Параметры**:
- `INDEX` (опциональный) - номер слота (0-3), если не указан, используется текущий активный

### ACE_FEED
**Назначение**: Подает филамент из указанного слота на заданную длину

**Синтаксис**: `ACE_FEED INDEX=<номер_слота> LENGTH=<длина> [SPEED=<скорость>]`

**Параметры**:
- `INDEX` (обязательный) - номер слота (0-3)
- `LENGTH` (обязательный) - длина подачи в мм (>0)
- `SPEED` (опциональный) - скорость подачи в мм/с (по умолчанию: значение `feed_speed`)

**Пример**: `ACE_FEED INDEX=0 LENGTH=100 SPEED=25`

### ACE_RETRACT
**Назначение**: Втягивает филамент обратно в ACE Pro

**Синтаксис**: `ACE_RETRACT INDEX=<номер_слота> LENGTH=<длина> [SPEED=<скорость>]`

**Параметры**:
- `INDEX` (обязательный) - номер слота (0-3)
- `LENGTH` (обязательный) - длина втягивания в мм (>0)
- `SPEED` (опциональный) - скорость втягивания в мм/с (по умолчанию: значение `retract_speed`)

**Пример**: `ACE_RETRACT INDEX=1 LENGTH=50 SPEED=30`

### ACE_CHANGE_TOOL
**Назначение**: Выполняет смену инструмента (филамента)

**Синтаксис**: `ACE_CHANGE_TOOL TOOL=<номер_инструмента>`

**Параметры**:
- `TOOL` (обязательный) - номер инструмента (-1 для выгрузки, 0-3 для загрузки)

**Пример**: `ACE_CHANGE_TOOL TOOL=2`

### ACE_GATE_MAP
**Назначение**: Настраивает параметры филамента для указанного слота

**Синтаксис**: `ACE_GATE_MAP GATE=<номер_слота> [COLOR=<цвет>] [TYPE=<тип>] [TEMP=<температура>]`

**Параметры**:
- `GATE` (обязательный) - номер слота (0-3)
- `COLOR` (опциональный) - цвет филамента
- `TYPE` (опциональный) - тип материала (PLA, PETG, ABS и т.д.)
- `TEMP` (опциональный) - температура печати

**Пример**: `ACE_GATE_MAP GATE=0 COLOR=red TYPE=PLA TEMP=210`

### ACE_ENDLESS_SPOOL
**Назначение**: Включает или отключает режим "бесконечной катушки"

**Синтаксис**: `ACE_ENDLESS_SPOOL [ENABLE=<значение>]`

**Параметры**:
- `ENABLE` (опциональный) - 1 для включения, 0 для отключения (по умолчанию: 1)

**Пример**: `ACE_ENDLESS_SPOOL ENABLE=1`

### ACE_DEBUG
**Назначение**: Отладочная команда для тестирования системы

**Синтаксис**: `ACE_DEBUG`

**Параметры**: Нет

**Описание**: Выполняет тестовое втягивание филамента из слота 0

## Системные методы

### Служебные функции

#### _calc_crc(buffer)
**Назначение**: Вычисляет контрольную сумму CRC для проверки целостности данных

**Параметры**:
- `buffer` - буфер данных для вычисления CRC

**Возвращает**: 16-битная контрольная сумма

#### _send_request(request)
**Назначение**: Отправляет JSON-запрос в ACE Pro через последовательный интерфейс

**Параметры**:
- `request` - словарь с данными запроса

**Протокол пакета**:
```
[0xFF 0xAA] [length] [JSON payload] [CRC] [0xFE]
```

### Управление соединением

#### _connect()
**Назначение**: Устанавливает соединение с устройством ACE Pro

**Особенности**:
- Автоматическое переподключение при сбоях
- Получение информации о прошивке устройства
- Восстановление активных функций feed assist

#### _serial_disconnect()
**Назначение**: Разрывает соединение с устройством

**Действия**:
- Закрытие последовательного порта
- Остановка таймеров чтения/записи
- Сброс флагов соединения

### Обработка датчиков

#### extruder_sensor_handler(eventtime, is_filament_present, runout_helper)
**Назначение**: Обрабатывает события от датчика филамента экструдера

**Функции**:
- Определение окончания филамента во время печати
- Активация режима "бесконечной катушки"
- Автоматическая пауза печати при окончании материала
- Поиск и загрузка подходящего материала

**Логика "бесконечной катушки"**:
1. Обнаружение окончания филамента
2. Поиск слота с совместимым материалом
3. Автоматическая смена инструмента
4. Продолжение печати

### Внутренние методы управления

#### _extruder_move(length, speed)
**Назначение**: Перемещает экструдер на заданное расстояние

**Параметры**:
- `length` - расстояние в мм (может быть отрицательным для втягивания)
- `speed` - скорость движения в мм/с

#### _park_to_toolhead(tool)
**Назначение**: Подает филамент от ACE до головки инструмента

**Этапы**:
1. Подача филамента через Bowden-трубку
2. Обнаружение филамента датчиком экструдера
3. Активация feed assist для точной подачи
4. Продвижение до датчика головки (если есть)
5. Доподача до сопла

#### wait_ace_ready()
**Назначение**: Ожидает готовности системы ACE к выполнению команд

**Логика**: Блокирует выполнение до получения статуса `ready`

## Состояния системы

### Статусы слотов
- `empty` - слот пуст, нет филамента
- `ready` - филамент загружен и готов к использованию
- `busy` - слот в процессе операции

### Позиции филамента
Система отслеживает текущую позицию филамента:
- `spliter` - филамент в разветвителе ACE
- `bowden` - филамент в Bowden-трубке
- `toolhead` - филамент в головке инструмента
- `nozzle` - филамент доведен до сопла

### Статусы сушилки
- `stop` - сушилка остановлена
- `running` - процесс сушки активен

**Параметры сушки**:
- `target_temp` - целевая температура
- `duration` - общее время сушки
- `remain_time` - оставшееся время

### Информация о системе
```json
{
  "status": "ready|busy",
  "temp": 25,
  "fan_speed": 7000,
  "enable_rfid": 1,
  "slots": [
    {
      "index": 0,
      "status": "ready|empty|busy",
      "sku": "материал_код",
      "type": "PLA",
      "color": [255, 0, 0]
    }
  ]
}
```

## Обработка ошибок

### Типы ошибок

#### Ошибки связи
- **Таймаут соединения**: Автоматическое переподключение через 1 секунду
- **Ошибки CRC**: Повторная отправка пакета
- **Потеря соединения**: Переход в режим переподключения

#### Ошибки валидации параметров
- **Неверный индекс слота**: Должен быть 0-3
- **Неверная температура**: 1-55°C для сушилки
- **Неверная скорость**: Должна быть >0
- **Неверная длина**: Должна быть >0

#### Ошибки устройства
- **Пустой слот**: Попытка загрузки из пустого слота
- **Заблокированный филамент**: Филамент застрял в системе
- **Ошибки сушилки**: Перегрев или неисправность

### Механизмы восстановления

#### Автоматическое переподключение
```python
def _connect(self, eventtime):
    # Попытка подключения каждую секунду
    # Восстановление активных функций
    # Проверка версии прошивки
```

#### Обработка callback'ов
```python
def callback(self, response):
    if 'code' in response and response['code'] != 0:
        raise ValueError("ACE Error: " + response['msg'])
    # Обработка успешного ответа
```

## Интеграция с Klipper

### События системы
- `klippy:ready` - инициализация после запуска Klipper
- `klippy:disconnect` - корректное закрытие при остановке

### Сохранение переменных
Система использует модуль `save_variables` для персистентного хранения:

#### Переменные состояния
- `ace_current_index` - текущий активный инструмент (-1 если нет)
- `ace_filament_pos` - позиция филамента (spliter/bowden/toolhead/nozzle)
- `ace_endless_spool` - состояние режима бесконечной катушки

#### Переменные конфигурации
- `ace_gate_color` - массив цветов филаментов по слотам
- `ace_gate_type` - массив типов материалов по слотам
- `ace_gate_temp` - массив температур печати по слотам

#### Системные переменные
- `ace__revision` - версия конфигурации для отслеживания изменений

### Поддерживаемые макросы

#### Обязательные макросы
Эти макросы должны быть определены в конфигурации:

**`_ACE_PRE_TOOLCHANGE FROM=<старый> TO=<новый>`**
- Выполняется перед началом смены инструмента
- Может содержать логику подготовки (например, парковка осей)

**`_ACE_POST_TOOLCHANGE FROM=<старый> TO=<новый>`**
- Выполняется после завершения смены инструмента
- Может содержать логику финализации (например, калибровка давления)

**`_ACE_ON_EMPTY_ERROR INDEX=<слот>`**
- Вызывается при попытке загрузки из пустого слота
- Позволяет реализовать пользовательскую обработку ошибок

#### Конфигурационные макросы
Указываются в параметрах конфигурации:

**`poop_macros`** - макрос очистки сопла
- Выполняется после загрузки нового филамента
- Обычно включает выдавливание материала для очистки

**`cut_macros`** - макрос обрезки филамента
- Выполняется при смене с позиции "nozzle"
- Может использовать механическое или термическое обрезание

### Интеграция с датчиками

#### Датчик экструдера
```python
[filament_switch_sensor extruder_sensor]
switch_pin: ^gpio21
pause_on_runout: False
```

#### Датчик головки инструмента (опционально)
```python
[filament_switch_sensor toolhead_sensor]
switch_pin: ^gpio22
pause_on_runout: False
```

### Статус-объект для Mainsail/Fluidd

Система предоставляет статус через метод `get_status()`:

```python
{
    'temp': 25,                    # Текущая температура
    'dryer_status': {...},         # Статус сушилки
    'gate_color': ['red', 'blue'], # Цвета по слотам
    'gate_material': ['PLA', 'PETG'], # Материалы
    'gate_temp': [210, 240],       # Температуры печати
    'active_gate': ['ready', 'empty'], # Статусы слотов
    'selected_gate': 0,            # Активный слот
    'endless_spool': True          # Статус бесконечной катушки
}
```

## Примеры конфигурации

### Минимальная конфигурация
```ini
[ace]
serial: /dev/ttyACM0
extruder_sensor_pin: ^gpio21
poop_macros: PRIME_NOZZLE
cut_macros: CUT_FILAMENT
```

### Расширенная конфигурация
```ini
[ace]
serial: /dev/ttyACM0
baud: 115200
extruder_sensor_pin: ^gpio21
toolhead_sensor_pin: ^gpio22
feed_speed: 25
retract_speed: 30
toolchange_retract_length: 120
toolhead_sensor_to_nozzle: 50
max_dryer_temperature: 60
poop_macros: PRIME_NOZZLE TEMP={material_temp}
cut_macros: CUT_FILAMENT RETRACT=5
```

### Пример макросов
```gcode
[gcode_macro PRIME_NOZZLE]
gcode:
    G1 E20 F300        # Выдавить 20мм для очистки
    G1 E-2 F1800       # Небольшой откат

[gcode_macro CUT_FILAMENT]
gcode:
    G1 E-5 F1800       # Откат перед обрезкой
    # Логика активации резака

[gcode_macro _ACE_PRE_TOOLCHANGE]
gcode:
    SAVE_GCODE_STATE NAME=toolchange
    G28 X Y            # Парковка осей

[gcode_macro _ACE_POST_TOOLCHANGE]
gcode:
    RESTORE_GCODE_STATE NAME=toolchange
    # Дополнительная калибровка если нужна
```

## Устранение неполадок

### Проблемы соединения
**Симптом**: `Unable to communicate with the ACE PRO`
**Решение**:
1. Проверить правильность пути к порту
2. Убедиться что устройство подключено
3. Проверить права доступа к порту
4. Перезапустить Klipper

### Проблемы с филаментом
**Симптом**: `Filament stuck`
**Решение**:
1. Проверить правильность подключения датчиков
2. Убедиться в отсутствии засоров в Bowden-трубке
3. Проверить калибровку длин перемещений

### Проблемы сушилки
**Симптом**: Ошибки температуры
**Решение**:
1. Проверить настройку `max_dryer_temperature`
2. Убедиться что температура не превышает лимит
3. Проверить исправность температурного датчика
